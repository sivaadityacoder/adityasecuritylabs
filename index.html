// The Platform

ASL V6 Engine

Research-grade vulnerability assessment and red-teaming engine for Python and AI agent codebases. Free and open-source under the MIT License.

01

10 Security Analyzers

Examines code for OWASP Top 10 LLM and Agent vulnerabilities, including prompt injection sinks, goal hijacking, and unsafe code execution.

02

AST Contextual Filtering

Parses Python syntax trees to ignore test suites, mock files, and docstrings. This eliminates around 98% of false positive alerts.

03

Live Docker Verification

Runs untrusted code snippets inside isolated ephemeral Docker containers to confirm whether an injection is exploitable in a live runtime.

Generates structured code fixes and patch suggestions. Works offline using deterministic AST rules, or connects to NVIDIA developer API.
